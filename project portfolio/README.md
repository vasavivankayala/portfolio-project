# Vasavi Vankayala — Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript, using the information in my resume.

## Sections
- Introduction and contact links
- About me
- Technical skills
- E-Commerce Product Store project
- Education, certifications and extracurricular activities
- Downloadable resume

## Run locally
No installation is required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local development server, you can use the VS Code **Live Server** extension.

## Publish with GitHub Pages
1. Create a public GitHub repository named `vasavivankayala.github.io` (or another repository name).
2. Upload all files and folders from this project. Keep `index.html` in the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your site URL will be shown in the Pages settings.

## Before publishing
- Check that your email, GitHub and LinkedIn links are correct.
- In the Projects section, replace the GitHub profile link with the direct repository URL for the E-Commerce Product Store when available.
- Review the resume PDF and confirm you are comfortable making it publicly downloadable.
